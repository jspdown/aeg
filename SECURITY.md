# Security

## Report a vulnerability

Do not open a public issue for a vulnerability.
Report it privately on [GitHub](https://github.com/jspdown/aeg/security/advisories/new).

Give the configuration, the request that the agent sends, and what AEG does with it.

## Threat model

The [threat model](docs/threat-model.md) tells what AEG protects and what it does not.
A problem in the "What AEG does not protect against" section is a known limit, and not a vulnerability.
